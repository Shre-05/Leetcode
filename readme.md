### My Solution Format

Where applicable, each problem file includes:

1. **Problem Statement** — Description, examples and constraints.
2. **Java Solution** — Implementation in Java.
3. **Python Brute Force** — A straightforward approach to understand the logic.
4. **Optimized Python Solution** — An improved approach where applicable.
5. **Complexity Analysis** — Time and auxiliary space complexity.
6. **Key Learnings** — Important observations and common mistakes.

Not every problem necessarily has all these approaches.
